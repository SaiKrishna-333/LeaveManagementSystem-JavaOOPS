# Leave Management System (Java OOP)

Monthly Assignment – Module 2: Object-Oriented Programming

## Objective
Build and refactor a console-based Java Leave Management System using Object-Oriented Programming principles.

## Initial Design
The system models employees, leave rules, leave requests, and role-specific employee types. The final design uses an abstract `Employee` class, a `LeavePolicy` interface, employee subclasses, a separate `LeaveRequest` model, and custom checked exceptions.
